# 공통 프로젝트 기획

## 확인된 현황

- Orvantro를 공통 협업 문서의 거점으로 사용하기로 했습니다. 이 저장소에는 지도, 기획, 작업 기록을 둡니다.
- 관련 저장소는 `orvantro`, `orvantro-insights`, `marginkit-pro-beta`, `markit-pro-beta`, `sellerbill`, `feeroi`입니다.
- 각 저장소의 `main` 루트에서 정적 웹 파일을 확인했습니다. 제품의 실제 개발 소스 위치와 활성 배포 설정은 아직 확인되지 않았습니다. 상세 목록은 [프로젝트 지도](PROJECT-MAP.md)를 참조하세요.
- 공통 문서를 읽고 기록을 이어받는 수동 협업만 준비합니다. Cursor와 Codex 사이의 자동 대화 또는 문서 동기화는 구축되지 않았습니다.

## 미승인 제안

- 실제 소스 위치를 확인한 뒤 각 제품 저장소에 최소한의 공통 문서 링크를 둘지 별도 결정합니다. 이 문서만으로 다른 저장소의 규칙이 적용되지는 않습니다.
- 소스 저장소와 배포 저장소가 분리되어 있다면 이를 지도에 기록하고, 배포 파일 변경은 별도 요청과 검증 없이 하지 않습니다.
- 문서의 공개 게시와 `main` 병합은 각각 검토·승인 절차를 거칩니다. 현재 문서 작성이나 초안 PR 승인이 병합·배포 승인까지 뜻하지 않습니다.

## 다음 확인

1. 여섯 제품의 실제 소스 저장소 또는 Cursor 작업 경로를 확인합니다.
2. 각 배포 저장소의 실제 게시 설정과 공개 URL을 확인합니다.
3. 다른 저장소에 공통 문서를 연결하는 방법과 적용 시점을 별도 결정합니다.
